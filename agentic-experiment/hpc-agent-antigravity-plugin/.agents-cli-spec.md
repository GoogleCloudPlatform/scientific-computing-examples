# Agent Spec

## Overview
An HPC orchestrator agent capable of managing high-performance computing and batch workloads on Google Cloud. It uses skills from the Google Cloud Platform scientific-computing-examples repository.

## Tools Required
- **Slurm Cluster Management Skill:** Manage Slurm jobs and queues.
- **Google Cloud Batch Skill:** Programmatically submit and monitor Google Cloud Batch jobs.
- **HPC Toolkit Skill:** Manage infrastructure using Google Cloud HPC Toolkit.

## Constraints & Safety Rules
- Prototype mode (local development first, no explicit deployment target initially).
- Follow standard safety guardrails for infrastructure creation/deletion.

## Success Criteria
- The agent successfully scaffolds using ADK conventions.
- The 3 HPC skills are successfully ported and integrated into the agent's toolset.
